# BookWorms


BookWorms is a book discovery and review platform which is designed to help readers quickly find books, explore information about books and share their own thoughts on a book. In a wrap, the app allows fast, intuitive searching with a community-driven review system that allows users to decide what to read next.

BookWorms is suited to all types of readers, from casual readers just looking for the next book to book clubs wanting a shared review space. With features like book searches, book details, review system and user profiles it reduces the hardship of finding new books to read.
